# Latihan Mandiri 1 — Validasi Tambah Tugas

## Tujuan

Menambahkan validasi pada halaman Tambah Tugas.

## Ketentuan

Judul tugas:

- wajib diisi;
- minimal terdiri dari 3 karakter.

## Konsep

- Form
- GlobalKey<FormState>
- TextFormField
- validator

## Hasil

Jika judul kosong atau kurang dari 3 karakter, akan muncul pesan error.
Jika valid, tugas dapat disimpan.
