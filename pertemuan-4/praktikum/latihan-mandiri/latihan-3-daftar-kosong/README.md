# Latihan 3 — Daftar Kosong

## Tujuan

Menangani kondisi ketika API mengembalikan daftar kosong.

## Kondisi

Apabila:

```dart
data.isEmpty
```

maka aplikasi menampilkan:
```dart
Tidak ada data
```

## Pengujian

Untuk simulasi daftar kosong, data dapat sementara dibuat:
```dart
final List<dynamic> data = [];
```

Setelah pengujian selesai, kembalikan kode agar data kembali diperoleh
dari API.
