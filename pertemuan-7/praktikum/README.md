| Keterangan | Detail |
|---|---|
| Mata Kuliah | Pemrograman Mobile |

| Status | Pengerjaan tugas proyek |
| Proyek | TabungKu |

## Pendahuluan

Pada Pertemuan 7, pengerjaan difokuskan pada penyelesaian tugas proyek aplikasi mobile menggunakan Flutter. Oleh karena itu, dokumentasi implementasi dan hasil pengerjaan dipusatkan pada folder **`tugas/tabungku/`**.

Folder praktikum ini tidak memiliki laporan praktikum terpisah. Dokumentasi proyek, kode sumber, screenshot, dan pengujian dapat dilihat melalui folder tugas yang telah disiapkan.

## Pengalihan Dokumentasi

Seluruh dokumentasi pengerjaan proyek Pertemuan 7 diarahkan ke lokasi berikut:

```text
pertemuan-7/
├── doc-tugas/
│   └── modul-praktikum-flutter-pertemuan-7.pdf
├── praktikum/
│   └── README.md
└── tugas/
    ├── README.md
    └── tabungku/
        ├── README.md
        ├── lib/
        ├── test/
        ├── screenshots/
        ├── pubspec.yaml
        └── pubspec.lock
```

**Keterangan:**

- `doc-tugas/` berisi dokumen modul Pertemuan 7.
- `praktikum/README.md` memberikan informasi bahwa pengerjaan difokuskan pada tugas proyek.
- `tugas/README.md` berisi pengantar pengerjaan tugas Pertemuan 7.
- `tugas/tabungku/` berisi implementasi aplikasi, dokumentasi lengkap, screenshot, dan berkas pendukung proyek.
